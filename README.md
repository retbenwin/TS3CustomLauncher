Launcher custom de Los Sims 3:

• Ejecuta el juego como un proceso con una prioridad alta por defecto (mejora el rendimiento).
• Al iniciar el custom launcher, se elige una pantalla de carga de forma aleatoria (de las expansiones y accesorios).

Nota: las pantallas de carga solo funcionan si se tiene instalada la ultima expansión "Into The Future" ("Hacia el futuro"), de lo contrario tendrás que remplazar/eliminar/agregar tus propios mods de tipo "loading screen" de acuerdo a tu ultima expansión/pack (según su fecha de lanzamiento) en la carpeta "LoadingScreens".
